# The "Gorislavl" Route for Train Simulator Classic

**Current route version:** 0.8061123

The author of the route and most of its assets is Ivan "hawthorn" Kostin, aka komurka.

## Distribution Rules

You may reupload the route as long as proper credit is given. Feel free to improve it, create scenarios, and develop the concept further, provided that I am credited as the original author.

**Download:**

[https://drive.google.com/file/d/1fD3tL9eJETmN_ZGlm9JkzyCDWoFrtqME/view?usp=drive_link](https://drive.google.com/file/d/1fD3tL9eJETmN_ZGlm9JkzyCDWoFrtqME/view?usp=drive_link)

**Alternative link:** [https://disk.yandex.ru/d/RCTHle7QvsbBWQ](https://disk.yandex.ru/d/RCTHle7QvsbBWQ)

## Installation

1. Navigate to the game folder (the default location for the Steam version is `C:\SteamLibrary\steamapps\common\RailWorks`).
2. Open **Utilities.exe**.
3. Go to the **Package Manager** tab, click **Install**, and select the previously downloaded `.rwp` file.
4. Repeat the same process for the dependency `.rwp` files listed below.

## Troubleshooting

If you experience problems with the route:

* Make sure that you have installed all the required dependencies.
* Try installing this patch into the game: [https://drive.google.com/file/d/1BkM9NCR-n0BWPC7GGt16GlMbl-_CVqCA/view?usp=drive_link](https://drive.google.com/file/d/1BkM9NCR-n0BWPC7GGt16GlMbl-_CVqCA/view?usp=drive_link)
* Many problems can be solved by manually creating a copy of the route through the in-game menu and then launching that copy.
* The route has been confirmed to work correctly for most players. There is most likely a solution to your problem as well, so try searching for it online.
